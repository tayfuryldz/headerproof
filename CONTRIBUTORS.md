# Contributors

HeaderProof is maintained by [@TayfurYldz](https://github.com/TayfurYldz).

Community contributors are credited here after an accepted contribution reaches
`main`. Release notes also credit the people whose accepted work first ships in
that release.

## Community contributors

- [@PandaHUN777](https://github.com/PandaHUN777) — release smoke-test coverage and release binary CI integration ([#18](https://github.com/TayfurYldz/headerproof/pull/18))

## Credit policy

- Credit follows accepted work, not opened or pending pull requests.
- A contributor is listed once, using their GitHub handle when available.
- Release notes mention the contributor and the pull request(s) that shipped.
- Commit authorship is preserved when an external contribution is integrated.
- Bots and automated dependency updates are not listed as community contributors.
- `Co-authored-by` is used only when the named person actually co-authored the resulting commit.
